## Featured Projects

### [Agentic Retail Intelligence](https://github.com/Muxtadir/cmpe-295a-masters-project)

**Master's Project • San José State University**

A retail operations system that forecasts demand, finds which products are bought together, and turns those signals into inventory decisions. This is a team master's project. I implemented the FastAPI backend, the React/Vite command center, and the forecasting and inventory flow.

- Prophet demand forecasting, plus a PyTorch LSTM forecasting path
- Market-basket and association-rule analysis on retail invoices
- Inventory decision logic driven by the forecast
- PostgreSQL, Docker Compose, and JWT authentication

`Python` · `FastAPI` · `React` · `Vite` · `Prophet` · `PyTorch` · `PostgreSQL` · `Docker`

---

### [Chat-Craft](https://github.com/Chat-craft)

**Collaborative project • Distributed RAG-based knowledge Q&A platform**

Chat-Craft is a team platform that answers questions from an organization's own documents. The system handles document ingestion, semantic and vector search, LLM-based Q&A, a microservice architecture, and an embeddable chatbot. My part of that work is the scheduler and the analytics service.

**My public contributions**

- [Cron-job](https://github.com/Chat-craft/Cron-job) — a Go scheduler that checks Google Sheets and Docs for changes and records those updates
- [chat-metrics](https://github.com/Chat-craft/chat-metrics) — Python analytics over chat logs, using Pandas, scikit-learn, and charts

On the wider platform I also worked with FastAPI, MongoDB Atlas Vector Search, embeddings, LLM integration, and Next.js.

`Go` · `Python` · `FastAPI` · `MongoDB` · `scikit-learn` · `Next.js`

---

### [VulnScan](https://github.com/Muxtadir/vulnscan)

**Team project • Software security course**

DepSecScan is a Python CLI that scans dependencies for known vulnerabilities. It queries the NVD and GitHub Advisory APIs, matches package versions, ranks severity, suggests upgrades, and writes CLI, JSON, and HTML reports.

`Python` · `NVD API` · `GitHub Advisory API`
